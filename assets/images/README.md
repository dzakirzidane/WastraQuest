# Panduan Gambar untuk Busana Nusantara

## 📏 Ukuran Gambar yang Direkomendasikan

Untuk hasil terbaik di aplikasi quiz, gunakan spesifikasi berikut:

### Ukuran Ideal
- **Lebar**: 400px - 600px
- **Tinggi**: 400px - 600px  
- **Rasio**: **1:1 (persegi)** atau 4:3

### Format File
- **Format**: JPG atau PNG
- **Ukuran File**: Maksimal 500KB per gambar
- **Kualitas**: 80-90% (balance antara kualitas dan ukuran file)

## 📂 Nama File

File harus sesuai dengan yang ada di `questions.json`:

```
kebaya.jpg
ulos.jpg
baju_bodo.jpg
payas_agung.jpg
baju_kurung.jpg
koteka.jpg

ulee_balang.jpg

```

## 🎨 Tips Fotografi

1. **Fokus pada Pakaian** - Pastikan pakaian adat terlihat jelas
2. **Background Netral** - Gunakan background polos atau blur
3. **Pencahayaan Baik** - Hindari bayangan gelap
4. **Detail Terlihat** - Motif dan aksesoris harus jelas
5. **Crop Persegi** - Crop center untuk hasil terbaik

## 📍 Lokasi File

Simpan semua gambar di folder:
```
assets/images/
```

## ✅ Checklist

- [ ] 15 gambar pakaian adat sudah disiapkan
- [ ] Semua gambar berukuran 400x400px minimal
- [ ] Format JPG atau PNG
- [ ] Nama file sesuai dengan questions.json  
- [ ] Gambar sudah disimpan di assets/images/
- [ ] Ukuran file < 500KB per gambar

## 🔄 Setelah Menambah Gambar

Setelah menambahkan gambar:
1. Pastikan nama file sama persis dengan di `questions.json`
2. Jalankan `flutter pub get` (optional)
3. Restart aplikasi dengan hot reload (tekan 'r' di terminal)
4. Gambar akan otomatis muncul!

---

**Catatan**: Gambar pakaian adat sebaiknya menampilkan keseluruhan kostum dari depan dengan pose standar untuk konsistensi visual.
